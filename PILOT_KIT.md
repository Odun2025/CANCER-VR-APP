# OncoEase — Hospital Pilot Kit (10 patients, phones, offline)

## What you are testing (PRD Sec 28)
Helpfulness, not clinical efficacy. Measure: completion, self-reported usefulness, anxiety self-report, reuse intent, caregiver feedback.

## Kit checklist
- 2+ Android phones with `cancercompass-app.html` saved for offline (or hosted link) + backend optional (demo mode is fine for pilot)
- Printed consent script (also in-app consent modal, stored on-device)
- Paper backup forms (if phone battery dies)
- Wipe-data demo (footer → Wipe local data) after each participant if shared phones

## Protocol (per patient, ~25 min)
1. Consent (2 min): read script, tap “I understand”, note consent time. No names in app — use codes P01..P10.
2. Check-in + need (3 min): observe emotion → suggestion → patient chooses freely.
3. World session (5 min): Nigerian coast 3-min + 1 swap (garden). Note pause/switch use.
4. Relax + Learn (5 min): 1 breathing track + 1 education topic. Ask: “Was this clear?”
5. Care tab (5 min): add 1 dosage reminder, tick adherence, 1 milestone, symptoms check, journey stage.
6. Check-out (3 min): post emotion + “Did this help?” + CSV export demo (keep CSVs by code).
7. Interview (2 min): Would you use again? What confused you? What comforted you?

## Record (paper or sheet)
- Code, date, phone model, network (offline?), consent Y/N
- Completed? Y/N per step; drop-off point
- Helpfulness: Yes / A little / Not really / No
- Distress 1–5 before → after (self-report, not clinical)
- Quotes (anonymous), issues (buttons too small? text unclear? audio?)

## Safety rules (PRD Sec 22)
- General info only; escalate red-flags (fever, bleeding, severe vomiting, chest pain, breathing trouble, confusion) to staff immediately.
- No dose changes via app. No outcome promises. Stop anytime if tired.
- Shared phones: wipe between participants (footer button) + clear voice notes.

## Success bar (go/no-go to wider pilot)
- ≥7/10 complete core loop; ≥6/10 “Yes/A little” helpful; ≥6/10 would reuse; 0 safety incidents; top 3 confusions fixed.
